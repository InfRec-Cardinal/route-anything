## Setup
* Data: `data/coderouterbench/id_results_long.csv`, 9,999 tasks × 8 models, real scores in [0,1] and recorded token-price `cost_usd` estimates. Reference policy B = `claude-opus-4-6` on every task. Cheap primaries: `Qwen3-Max`, `kimi-k2.5`. 148 Qwen3-Max rows with `cost_source=missing_token_record_zero_total` (cost 0, score 0) are kept as recorded. One id_test task has Opus cheaper than kimi (0 for Qwen).
* Splits: **probing** (7,080 tasks) estimates every prediction primitive; **id_test** (2,919) is the only measurement set. Partitions: 9 dimensions (`dim9`), 21 dimension × source-benchmark cells (`cell21`; id_test sizes 4–327), and the pooled set (`all`).
* Verifier: exact, H = 1{score_cheap ≥ θ}, θ ∈ {1.0, 0.5}; noisy verifier flips the exact verdict with (β_fa, β_fr) ∈ {(0.1,0.1),(0.2,0.2)} (one fixed uniform per id_test task).
* Accounting (eq:accounting): V = H·Y_P + (1−H)·Y_B; D = cost_cheap + (1−H)·cost_Opus (cascade); direct: V = Y_B, D = cost_Opus. Dollars only (λ per dollar; latency is not used in Sec. 4). λ ∈ {0.1, 1, 10, 100} and λ = η_B(probing) = 34.727 $⁻¹.
* Primitives per cell (probing): p = P(H=1), v_h = E[Y_P | H=1], v_b = E[Y_B] (the paper's "value of going directly to that path"), a = E[cost_cheap], b = E[cost_Opus]. W_λ = λb + v_h − v_b (eq:margin); prediction J_casc − J_direct = pW_λ − λa (app:decisions proof).
* Fallback restores the reference exactly (fallback = Opus = B), so the "lossless fallback on misses" hypothesis holds by construction and is not tested.

## (a) prop:threshold details
Prediction formula with pooled primitives (Qwen3-Max, θ=1, probing): p = 0.2144, v_h = 1.000, v_b = 0.4297, a = $0.000532, b = $0.01237. W_1 = 1·0.01237 + 1 − 0.4297 = 0.5826, p* = λa/W_1 = 0.0009 ≪ p; predicted J_casc − J_direct = 0.2144·0.5826 − 0.000532 = 0.1244; measured 0.0706 [0.0618, 0.0800]. At λ = η_B = 34.7: predicted 0.196, measured 0.194 (the value-side and cost-side hypothesis violations happen to cancel there because Opus's value/cost on Qwen-hit tasks ≈ its overall efficiency). kimi θ=0.5: predicted 0.158 vs measured 0.032 at λ=1.

Exact accounting identity checked in code (`assert`, to 1e-12): J_casc − J_direct = p(λ·b_hit + v_h − v_b_hit) − λa with b_hit = E[C_B | H=1], v_b_hit = E[Y_B | H=1]. The as-stated formula substitutes (b, v_b). Decomposition, pooled Qwen θ=1 (in-sample): as-stated 0.126; fix only v_b → v_b_hit: 0.069; fix only b → b_hit: 0.127; exact 0.071 at λ=1. At λ=100: as-stated 0.328, fix-v_b 0.271, fix-b 0.489, exact 0.432 — the cost side dominates there.

FAIL cells (34 = 12 dim9 + 22 cell21) come in two kinds: (i) 17 rows where probing p ∈ [0.001, 0.06] but id_test has zero hits (code_refactoring/kimi, code_completion|he/kimi n=32, code_refactoring|canitedit/kimi n=4) — small-cell sampling, prediction CIs near 0; (ii) 17 rows at θ=0.5 (bug_fixing, code_completion, multi_language and their cell21 counterparts) where v_h = 0.78–0.86 is *below* E[Y_B | H=1] = 0.85–0.94: accepted cheap outputs lose value against Opus on exactly those tasks, which the miss-independent v_b cannot see. Per-λ decided agreement: dim9 0.83 / 0.80 / 0.97 / 1.00 / 1.00 for λ = 0.1 / 1 / 10 / 34.7 / 100; cell21 0.91 / 0.89 / 0.95 / 0.96 / 0.96. Noisy verifier (0.1, 0.1): decided 0.930 (dim9) / 0.892 (cell21); (0.2, 0.2): 0.926 / 0.960 (prediction uses p_eff = p(1−β_fr) + (1−p)β_fa and the accepted-value mixture).

## (b) refinement — why NOT INSTANTIABLE
prop:threshold's refinement stipulates a change of p by Δp at cost k "while preserving the other quantities", and the appendix says explicitly it "does not model a signal allowing contingent choice between fixed actions." The router decision files are exactly such contingent choices (which model answers), their inference cost k is not recorded anywhere in the release, and any construction from them changes a, v_h and E[Y_B | H=1]. Diagnostic (θ=1, λ=10, base cascade Qwen3-Max→Opus; refined primary = kimi where the router chose kimi): ft-27b Δp = +0.0079, stipulated Δp·W = 0.0055 vs realized 0.0051 [0.0027, 0.0077], break-even k ≈ $0.0005/task; routellm_mf Δp = −0.0007 (stipulated −0.0005) yet realized +0.0046 [0.0001, 0.0095] because E[Y_B | H=1] shifts by −0.021 — the "preserving" clause fails.

## (c) prop:voi details
Pooled Qwen θ=1: a = $0.000532, b = $0.01237, s = 0.214; k_max = a(b−a)/b = $0.000509. k = $1e-4: band (0.0084, 0.812) ∋ s → predicted info; realized C_info − min(C_casc, C_direct) = −$0.000304/task [−0.000304, −0.000278]. k = $5e-4: band (0.042, 0.060) ∌ s → predicted cascade; realized +$0.000096 [0.000096, 0.000122]. Per-cell realized costs: C_casc = mean(cost_cheap + (1−H)cost_Opus), C_direct = mean(cost_Opus), C_info = k + mean(H·cost_cheap + (1−H)cost_Opus) — the "exact information" is the data's own sufficiency label. Value-preservation restriction: at θ=1 committed cheap outputs have score 1 by definition, and V_cascade ≥ V_direct pointwise; θ=0.5 rows are included for completeness (V_casc 0.494 vs V_direct 0.438 pooled) but there the hypothesis "value-preserving outputs" is not met. The in-sample version differs from the prediction only through hit-conditional costs ((1−s)·a_miss vs (1−s)·a and s(b_hit − a_hit) vs s(b−a)); it never flips a decided sign.

## (d) Blackwell details
Z = 1{router chose this cheap model} (also Z = 1{chose any non-Opus model}); policy "cascade if Z=1 else direct"; k = 0 (router cost unknown) so the reported saving is gross. saving = min(C_casc, C_direct) − C_Z; perfect-information value = min(C_casc, C_direct) − C_perfect; fraction = saving / value (cells with value < $1e-6 blank). Negative fractions mean the gated policy costs more than the best uninformed action: classical routers and dimension_best send too many Qwen-insufficient tasks down the cascade and too many Qwen-sufficient tasks directly to Opus (P(H=1 | Z=0) = 0.15 vs a/b = 0.043). Also reported (`frac_captured_optimal_use_of_Z`): the Blackwell-optimal use of the same Z with cell-mean costs, f(s) − E f(s_Z), is 0.38 (ft-27b), 0.30 (ft-9b) and ≤ 0.05 for all others — most routers' posteriors s_Z lie on one side of a/b, so under the paper's cost model the signal has no decision value; the positive realized fractions of the finetuned family arise partly from within-branch cost heterogeneity (Opus is cheaper on Qwen-miss tasks).

## Circularity statement
The sufficiency event is the benchmark's ground-truth score (an oracle verifier), and it defines H, the committed value on a hit, the cascade's cost and the "exact information" of (c). Predictions use probing-split means only; measurements use id_test per-task outcomes only, so (a) and (c) are out-of-sample in the formula's *inputs*. C6 is algebra; C8 holds pointwise on any dataset with cost_cheap ≤ cost_Opus and is reported as a code check. The routers behind (d) were trained on the probing split (original train + validation per the data README) and decide on id_test; their inference cost is not in the data. What the experiment establishes: whether the paper's closed forms with cell-mean primitives reproduce realized signs and magnitudes on recorded token-price cost estimates and real scores; it does not test learning or the verifier.

## Limitations
* Router cost k is unknown (set to 0 in (d); hypothetical in (c)). Latency is not used (Sec. 4 is stated in dollars).
* Cells are small in places (canitedit n=4, he n=32, swebench n=19); several INCONCLUSIVE cells and all 9 (c) failures come from these.
* Bootstrap CIs resample tasks within cell; verifier coin flips are held fixed, so noisy-verifier CIs omit flip variance.
* The threshold's bite is weak at these prices: p* ≤ 0.03 for λ ≤ 100 and W_λ ≤ 0 occurs in one exact cell, so C1/C2 have little discriminating power versus "any hits" / "p ≥ a/b".
* Task streams are i.i.d.; no state dependence is needed for Sec. 4 and none was constructed.
