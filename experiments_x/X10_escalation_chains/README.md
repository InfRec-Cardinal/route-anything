# X10_escalation_chains — Proposition prop:attempts (escalation inside a loop) on CodeRouterBench, OFFLINE part

All numbers below are produced by `run.py` (seed 20260917; 1,000 paired task bootstraps per state; runtime 130.6 s on the M4; no API calls). Run with
`ACROUTER_DATA=data/agent-as-a-router/data ACROUTER_OUTPUTS=data/agent-as-a-router/outputs ../.venv/bin/python run.py`
(env `X10_NBOOT`, `X10_KMAX` override the defaults 1000 and 3).

Files: `run.py`, `results.json` (every number here with CIs; `claims`), `README.md`, `summary_for_paper.md`, `figures/fig1_conditional_success.pdf`, `figures/fig2_predicted_vs_realized.pdf`, `figures/fig3_chain_length.pdf`.
Auxiliary outputs regenerated by `run.py` (not in the CONVENTIONS list; kept for audit): `tables_autogen.md` (all per-λ / per-state tables), `best_chains.csv` (optimal vs marginal-planned chain per state × λ × config), `c2_pairs.csv` (all ordered model pairs), `segments_released_usd.csv.gz` and `segments_bcb_allzero_excluded_usd.csv.gz` (the 223,510 per-(state, chain, k, λ) segment rows of each dollar configuration).

**PENDING (not in this directory): the LIVE retry part** — same-model resampling k ≤ 3 on a ≤ 500-task subsample with sandbox verification, giving p_retry|fail and the ratio p_retry|fail / p_switch|fail. Same-model retry is **not observable offline** (the released matrix holds one recorded output per task and model), so only the switch case is reported here.

## Setup

* **Data.** `$ACROUTER_DATA/coderouterbench/id_results_long.csv`: 9,999 tasks × 8 models, score ∈ [0,1], token-price `cost_usd`, `latency_ms`. Loader copied from `X3_threshold_voi/run.py`. Reference/terminal path B = `claude-opus-4-6` on every task. Primaries: the 7 non-Opus models. 148 Qwen3-Max rows with `cost_usd = 0` (missing token record) are kept as recorded.
* **Splits.** probing (7,080 tasks) fits every primitive; id_test (2,919) is only realized. States x: global (1), 9 dimensions (`dim9`), 21 dimension × source cells (`cell21`; id_test sizes 4–327).
* **Chains.** Ordered chains m₁ → … → m_K → Opus, K ∈ {1,2,3}: 7 + 42 + 210 = 259 chains. Oracle acceptance H_k = 1{score_{m_k} ≥ θ}, θ ∈ {1, 0.5}. Attempt k pays its own `cost_usd`; the task ends at the first acceptance; Opus is dispatched after the last failure.
* **Primitives per (state, chain, k) on probing** (state = attempts 1..k−1 failed): post-failure conditional success p_k = P(H_k = 1 | H₁ = … = H_{k−1} = 0); a_k = E[cost_{m_k} | state]; v_h = E[score_{m_k} | state, H_k = 1]; **state-matched terminal path** b_k = E[cost_Opus | state], v_{b,k} = E[score_Opus | state] (Opus on the same failure set, as the brief specifies); W_λ = λ b_k + v_h − v_{b,k}. Backward induction Π_k = max{J^direct_k, p_k v_h − λ a_k + (1 − p_k) Π_{k+1}} with J^direct_k = v_{b,k} − λ b_k and Π_{K+1} = J^direct_{K+1} (Opus on the all-fail set); Δ_{k+1} = Π_{k+1} − J^direct_{k+1} ≥ 0.
* **Rules compared** (sign of a predicted per-segment margin): **stated rule** p_k W_λ + (1 − p_k) Δ_{k+1} − λ a_k (prop:attempts as written); **naive rule** = the same recursion fed with the marginal P(E_m), unconditional a, v_h and the state's unconditional b, v_b (a marginal-planned chain, the brief's control); **exact DP** = attempt branch − J^direct_k with the state-matched primitives (diagnostic: it differs from the stated rule only through the identity J^direct_k = p_k J^direct_hit + (1 − p_k) J^direct_{k+1}, i.e. through the "terminal value is miss-independent" hypothesis behind eq:margin); **myopic rule** p_k W_λ ≥ λ a_k (Δ := 0, prop:threshold) against a naive-myopic control, both scored on the realized "attempt k, then Opus".
* **λ.** Dollars: {0.1, 1, 10, η_B = 34.727 score/$ (probing), 100}. Seconds basis (latency_ms, sequential steps add): the same five multiples of η_B(sec) = 0.0863 score/s on the 8,336 tasks with all 8 latencies logged (probing 5,883 / id_test 2,453; unlogged latency rows: glm-5 1,452, qwen3.5-plus 1,070, MiniMax-M2.7 541, kimi-k2.5 84, Qwen3-Max 2, Opus 1) — the literal values 0.1–100 per second are meaningless on that scale, so this is a labelled deviation.
* **Realization on id_test.** For every (state, chain, k, λ): on the tasks in the realized state (attempts 1..k−1 failed on id_test), ΔJ_λ = mean[J(attempt k, then follow the probing plan for the later attempts, Opus at the end) − J(Opus now)], J = V − λD; also the myopic variant (attempt k, then Opus). Paired bootstrap: 1,000 task resamples within the state's cell; a cell is **decided** if the 95% percentile CI excludes 0. Sign agreement = fraction of decided cells where sign(prediction) = sign(realized); always reported next to the naive rule and the always-/never-attempt baselines; its CI is the task-resampling distribution of the agreement rate (predictions fixed). Rows whose probing state is empty (no prediction exists) are excluded for every rule: 3,390 of 223,510 rows per dollar configuration, all in cell21. **Degenerate** rows (p_k = 0 on probing) are kept but also reported separately.
* **Variants.** `released` (matrix as is) and `bcb_allzero_excluded` (CONVENTIONS Addendum 2: 750 of 1,097 BigCodeBench tasks have score 0 for all 8 models — grader failures, treated as ungraded; universe 9,249 tasks, probing 6,556 / id_test 2,693, η_B = 36.68/$). The four bcb cells (`algorithm|bcb` 68 % all-zero, `code_completion|bcb` 67 %, `code_generation|bcb` 66 %, `data_science|bcb` 87 %) are **flagged** in every per-state table. Three non-bcb cells are 100 % all-zero at θ = 1 for every model (`bug_fixing|swebench`, `multi_language|multiple`, `test_generation|mbpp`) and are degenerate states.

## Hypothesis violations measured

1. **Terminal value is not miss-independent** (the hypothesis behind eq:margin's W_λ, already flagged by X3): E[Y_Opus | state, H_k = 1] − E[Y_Opus | state] = +0.30 on average over cell21 segments (+0.33 dim9, +0.26 global; 0.688 vs 0.430 at k = 1 in the worked example), while E[C_Opus | H_k = 1] − E[C_Opus] ≈ 0 (−0.001 cell21, +0.008 global). Opus is worth much more on the tasks a cheap model solves, so the stated rule over-values acceptance and errs on the false-attempt side (6,576 vs 44). The state-matched exact recursion removes most of it (0.932 vs 0.885 on cell21; MAE 0.040 vs 0.060). The stated rule remains the right sign in 88.5 % of decided cells because the option value and the price term dominate the sign at most states.
2. **Conditional independence** (the naive control): p_k / P(H_k) has median 0.4–0.5 after one failure and 0.25–0.30 after two; the marginal-planned recursion over-predicts attempting (naive wrong / stated right in 6,524 cells; 0 false stops).
3. **v_h constant across k**: exact at θ = 1 (v_h = 1); at θ = 0.5 v_h falls along the chain (0.89 → 0.82 → 0.73 in the worked example; range 0.50–1.00 over cell21 segments).
4. **Attempt costs on the failure set differ from the unconditional cost in both directions** (the naive recursion uses the unconditional a): in the global worked example the next model is cheaper on the tasks Qwen3-Max failed (kimi-k2.5 $0.00064 vs $0.00082, gpt-5.4 $0.0039 vs $0.0060), whereas across cell21 segments with k ≥ 2 (θ = 1) a_k exceeds the unconditional cost in 67 % of rows with a median ratio of 1.02.

## Limitations

* Acceptance is the benchmark's own score (oracle verifier); no verifier noise is modelled here. Same-model retry, and hence p_retry|fail / p_switch|fail, is not observable in this fixed-output replay; X7-b provides the live comparison.
* probing / id_test is a random split of one pool: out-of-sample here means split stability, not distribution shift; the only shift data (OOD176) has no probing split and is reported in-sample with n = 176, and its verdict is descriptive.
* Small cells (canitedit 4, swebench 19, he 32, bcb cells 22–33 id_test tasks) make many "decided" cells rest on few tasks; five fully degenerate states and 22,659 degenerate rows inflate every rule's agreement (non-degenerate rates reported alongside). The four bcb cells carry grader artifacts (Addendum 2); both variants are reported and C2–C4 verdicts do not change.
* The agreement CIs resample tasks with the decided set and the predictions held fixed, so they understate the uncertainty in which cells are decided.
* Seconds basis: 1,663 tasks lack a latency for some model and are dropped; Opus is the fastest path, so the rule's high agreement there is the never-attempt baseline.
